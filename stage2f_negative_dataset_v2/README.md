# Genuine invalid Talim dataset v2 — preflight implementation

This isolated workspace creates NEW canonical source parents and matched
valid/invalid images. The invalid renderer draws raw supplied tier cells and
never repairs them through canonical reconstruction. An independent inverse
renderer searches all legal glyph aliases/count encodings, without trusting the
assigned mutation label. Controls must pass both the original validator and the
inverse parser; invalids need changed pixels, consistent raw annotations and
zero legal canonical interpretations.

Supported categories: visibly distinguishable wrong-tier glyphs; noncanonical
two-glyph count order; missing required count token. Scope is the existing
fixed-font three-tier canonical implementation, not an expert claim about all
historical Talim. See reports/canonical_rule_audit.md and invalidity_categories.md.
B/X relabelings, metadata-only errors, unusual spacing/alignment, unsupported
count glyphs and image-quality failures do not fill the semantic-negative quota.
Conservative exclusions also cover C/Y, E/Z, G/[, I/\\, J/], K/^ and L/_ lookalikes;
wrong-tier source pools use the remaining14 visibly distinct symbol shapes.
An earlier120-image provisional preflight failed this visual-QA standard and is
preserved under dataset/quarantined_preflight_v0, marked ineligible. Only
dataset/preflight is the final review collection; do not merge the two.

Preflight target:30 NEW independent source families,10 per category,30 clean
invalids,30 matched valid controls,60 illumination variants (120 model images).
All are development-design, not protected test data. Dense long and multi-row
examples are included. AUTO_VERIFIED does not mean human-reviewed. The gallery
contains captions and full-resolution crops, but input PNGs have no answer labels.

The1,000-parent full target produces up to4,000 images:1,000 clean invalids,
1,000 controls and2,000 matched illumination variants. Counts are aspirational;
semantic collisions are excluded without backfilling and fundamental verification
failures stop the run. It is NOT automatically generated by this task.

Full generation requires the user to build a complete known historical-source
semantic index, then excludes overlap and preflight parent content. Splits are
assigned to source families before mutations/augmentation,70/15/15. Construction
QA precedes sealing; subsequent protected-test validation is hash-only, with no
test gallery or semantic debugging. New synthetic parents and source deduplication
do not establish independent real-world generalization.

Scanned-style scope is intentionally narrow: the existing scan engine applies
mild pointwise illumination, saved losslessly. Every atlas cell is independently
transformed and re-parsed. JPEG, blur, noise, rotation, perspective, resolution
and shadows need further verification and are not claimed here. Fonts remain
in their original location and are not copied.

Use RUN_IN_VSCODE.md after reviewing the preflight. Existing datasets, split
definitions, D1/E1/T1/F1, vocabulary and checkpoints are read-only. No model,
training, inference, threshold tuning or Git operation is part of these scripts.

Re-running with identical configuration/seed in a timestamped folder reproduces
the SAME source-family IDs; it does not create additional independent parents.
Never merge reproducible copies as independent samples.
