# Leakage and source ownership

Final preflight:30 independent canonical families,120 images, all in development_design.
Sources are freshly seeded through the existing canonical generator, not copied
from old images. Their exact semantic keys were compared with 1858 old
keys from1380 Stage1,150 general and326 positive-edge source records plus two
old fixture templates. No overlap was found. Stage2C/D and Stage2E replay/train/
development references are represented; Stage2F shares those sources. Old
protected-source metadata is used only to avoid overlap, never as performance,
rule-selection or generation evidence.

Global historical coverage is NOT yet complete: Codex did not sweep the full
100000/10000 archives. Full generation refuses this bounded index and requires
the manually built full index (100000 Stage1,10000 general,326 edges plus old
fixture templates, complete coverage and archive hashes). It then excludes these
keys and ALL final/quarantined preflight source keys. This covers known canonical
sources, not unknown external data or every perceptual near-duplicate.

All variants/mutations/controls share their canonical source owner. Reproducible
copies retain the same parent IDs. The quarantined first collection is not a
second independent dataset and must not be merged. Full source ownership is
assigned before mutation:70% development_design,15% validation_calibration,
15% protected_test. Construction QA precedes sealing; after sealing, protected
images/annotations/parent files receive hash-only verification. No protected
images appear in generated galleries, and semantic debugging is blocked.

This is synthetic source novelty in an audited canonical distribution, not a
claim of independent real-world generalization. Exposed old evaluation examples
are not relabeled as fresh test evidence. Historical preservation covers427 files
including E1/D1/T1/F1, canonical tools, original fixtures and old results.
